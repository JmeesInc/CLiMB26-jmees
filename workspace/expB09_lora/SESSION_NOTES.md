# expB09_lora — DA3 の自己教師あり LoRA 適応（内視鏡ドメイン）

## 動機（8/30 §8-9 の総括から）
- 連結方法（greedy / 最適化 / 一発 / 姿勢条件付け）を変えても v003 (4.374) を超えない
  → ボトルネックは**各窓の推定品質**。位相を 3 キーフレームずらすだけで 001_c が 2.49→6.08 と振れる
  = **同じフレームでも窓の文脈が違うと幾何が変わる**（文脈依存の不安定性）
- 窓スケールは `_apply_depth_alignment` で「単眼 metric 深度 vs any-view 深度の最小二乗比」として決まり、
  並進も同じ係数でスケールされる（`extrinsics[:,:,:3,3] *= scale_factor`）
- → **ラベル不要**で狙える: 重複する 2 窓で共有フレームの (相対姿勢, metric 深度) が一致するよう
  backbone を LoRA で微調整すれば、配備の s=1 連結の前提そのものを最適化できる

## 設計
- 対象: any-view DINOv2-giant backbone の `attn.qkv / attn.proj`（40 block × 2 = 80 Linear、rank 8 → 2.95M param）。
  metric 枝・head・cam_dec は凍結。`peft` 未導入のため `scripts/lora.py` に自前実装（+ block 単位 checkpointing）
- 損失（`train_lora.py`）: A=[k,k+12), B=[k+6,k+18)、共有 6 ビュー
  - `L_rot / L_trans`: 共有ビュー間の相対 (R, t) を一致（t は metric 単位のまま = s=1 の仮定）
  - `L_depth`: 共有フレームの metric 深度の相対 L1（両窓 conf 中央値以上の画素）
  - `L_anchor`: 凍結モデル（LoRA off）の窓 A 出力に近づける（崩壊防止, w=0.2）
- データ（`prep_clips.py`）: trainval 実系列から 12 s クリップ×20/系列、stride 6、kb4 rectify、長辺 504 JPEG。
  **除外: 公式 test split 18 本（禁止）+ Seq_001/Seq_003（実 CV クリップの親、CV の独立性維持）**
- 評価: `predict_cond.py` に `DA3_LORA=<pt>` 追加 → 実 CV 4 本（`expB04_realcv/run.sh LORA=...`）+ sim 回帰

### ★コンテナ回帰で発覚: LoRA は bf16 推論で崩れる
v004 コンテナ（`DA3_PRECISION=auto` → bf16）の sim 6 本: **8.87mm**（Seq_0〜5 = 7.98/9.39/9.53/9.48/5.96/10.85）。
ホスト fp16 では 5.25、基準（bf16, v003 コンテナ）4.11。全系列一様に悪化 = 精度の系統的相互作用。
LoRA は fp16 autocast で学習しており、評価機 RTX 5090 も `auto` なら bf16 になるため**そのまま出すと LB で崩壊**する。
→ Dockerfile に `ENV DA3_PRECISION=fp16` を固定し再ビルド・再回帰（sim + 実 4 本）。
教訓: **adapter は学習時と同じ dtype で推論する**。コンテナ回帰を sim でも回したから捕まえられた
| E @300 | 4.711 | 5.29 | 7.91 | 3.56 | 2.59 | 4.79 |
- run E 停止。回転アンカー付きでも @100 以降は悪化のみ
- **訂正**: bf16 崩壊は sim 限定。v004 コンテナ（bf16）の実クリップ回帰は **4.09 / 4-4 / tree OK**（ホスト fp16 4.075 と同等）。
  fp16 固定は「下振れ無しの安全策」として維持（学習精度と一致、5090 でも高速）
- **再訂正: sim 8.87 の正体は test.sh の設定**。`DA3_RECTIFY` 既定 1 で pinhole sim に kb4 平均キャリブの rectify を掛けていた
  （ホスト評価は rectify=0）。さらに `-e DA3_PRECISION=auto` がイメージの fp16 固定を上書き（本番は -e 無しなので固定が効く）。
  精度も LoRA も無関係。→ sim は `DA3_RECTIFY=0 DA3_PRECISION=fp16` で再回帰
