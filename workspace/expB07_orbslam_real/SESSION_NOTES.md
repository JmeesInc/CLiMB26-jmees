# expB07_orbslam_real — ORB-SLAM3（古典 SLAM）の実データ CV

## 目的
別アーキ探索の基準点。上位チーム（0.015〜0.017 s/f）は実時間級なので古典/軽量系の可能性があり、
公式ベースラインの ORB-SLAM3 を **v002 と同じ kb4→pinhole rectify** を掛けた実クリップで採点する。

## 手順
- `rectify_clips.py`: 実 4 クリップを rectify して lossless mp4 化、pinhole K から ORB 用 yaml を系列別に生成
- 公式 docker `endovis-orbslam-submission:ci` + `expA00/scripts/sim_entrypoint.sh`（SETTINGS 差替）、EXECUTIONS=3
- 落とし穴: docker はマウント外への symlink を辿れない → 入力は実体コピー

## 判断
- **不採用**。4 クリップ中 2 つが失敗（climb では ATE 25mm 固定ペナルティ）。成功クリップでも連鎖に劣る
- ただし **回転は追跡できた区間で圧倒的に良い**（003_a: 1.24° vs 連鎖 5.18°）。
  LB 上位の rot 3〜4° は特徴点ベースの回転推定が効いている可能性 → 回転だけ古典で補う「回転ハイブリッド」は
  tie-break 圏に入ったときの選択肢として記録
- ラン間分散が極端（003_a ±11.2）＝非決定性が強く、5 ラン平均でも安定しない
